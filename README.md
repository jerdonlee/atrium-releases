# Atrium releases

Windows downloads for Atrium, a worship and media presentation application.

## Install

Download the Windows x64 MSI from the [latest release](https://github.com/jerdonlee/atrium-releases/releases/latest). It installs to `C:\Program Files\Atrium`, includes its runtime and content library, and creates a Start menu shortcut.

## Update

In Atrium, open **Settings → Check for updates**. Available updates download with SHA-256 verification before opening Windows' administrator prompt. Your settings and services remain in your user folders.

Each release includes the MSI, `latest.json` for update detection, and `SHA256SUMS.txt` for independent verification.

This repository distributes releases only. Application source is maintained in a separate private repository. PDF import and live native PowerPoint mirroring remain under development.
